# Security Policy

DiskAnalyzer can inspect raw NTFS structures and can invoke Windows shell operations such as deletion and permanent deletion. Please handle suspected vulnerabilities carefully and do not include private disk contents in a public report.

## Supported versions

Security fixes will target the latest published release and the default development branch.

## Reporting a vulnerability

Please do not open a public GitHub Issue for a suspected vulnerability. After the repository is published, use GitHub Security Advisories and the **Report a vulnerability** flow when it is available. If private reporting is not yet enabled, contact the maintainer through the GitHub profile before disclosing technical details publicly.

Include only the information needed to reproduce the issue, and redact personal paths, filenames, credentials, and disk contents.
